# AI Engine Application Events

## Published Event Types
- `AiConversationCreated`: Fired when a new AI conversation session is initialized.
- `AiPromptSubmitted`: Fired when a user submits a prompt.
- `AiResponseGenerated`: Fired when AI Co-Pilot finishes generating a response.
- `AiInsightGenerated`: Fired when strategic insights are scanned and generated.
- `AiRecommendationApplied`: Fired when an AI system recommendation is applied.
- `AiCoachingSessionCompleted`: Fired when a 1-on-1 coaching session completes.
- `AiQuotaExceeded`: Fired when a user reaches their daily prompt limit.
