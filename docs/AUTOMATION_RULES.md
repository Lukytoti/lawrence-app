# Reusable Condition Rules Engine

## 1. Supported Operators
- `equals`, `notEquals`
- `greaterThan`, `lessThan`, `greaterThanOrEqual`, `lessThanOrEqual`
- `contains`, `in`, `notIn`, `exists`, `isEmpty`
- `AND`, `OR` logical operator trees.

## 2. Dynamic Evaluation
Evaluates live context payload against condition trees without maintaining duplicate cached business data as a source of truth.
