# Command Palette & Keyboard Shortcuts — Module 17

## Keyboard Accessibility
- Keybinding: `Cmd+K` or `Ctrl+K` launches the command palette from anywhere in the application.
- Navigation: `Up/Down` arrow keys navigate command suggestions; `Enter` executes selected action; `Esc` closes.

## Command Categories & Action Dispatching
1. **Navigation Shortcuts**: Jump directly to overview, CRM, Network tree, Billing, Automation, AI co-pilot.
2. **Quick Actions**:
   - `CREATE_TASK`: Prompt 04 Task API
   - `CREATE_LEAD`: Prompt 06 Lead API
   - `CREATE_INVOICE`: Prompt 11 Invoice API
   - `CREATE_RETENTION_CASE`: Prompt 12 Retention API
   - `EXECUTE_WORKFLOW`: Prompt 13 Automation Engine
   - `DISPATCH_NOTIFICATION`: Prompt 14 Dispatcher Engine
3. **AI Assistant Mode**: Prepend `?` or type natural language prompt to route directly to Prompt 15 AI Executive Co-Pilot.
