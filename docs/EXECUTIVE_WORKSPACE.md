# Executive Command Workspace — Module 17

## Executive KPI Aggregation
Combines key performance indicators across 10 business domains:
- **People**: Total Network Members, Active Members, Org Relationships
- **Productivity**: Tasks Due Today, Overdue Tasks, Completed Tasks, Personal Pending
- **CRM**: Active Opportunities, Pipeline Value Total (₦), New Prospects Today
- **Services**: Active Projects, Deliverables Pending Client Review
- **Billing**: Outstanding Invoices, Total Overdue Unpaid Amount (₦)
- **Retention**: At-Risk Clients, Open Retention Cases
- **Automation**: Active Workflows, Total Automation Executions Today
- **Communication**: Total Dispatched Messages Today
- **AI Co-Pilot**: Conversations Count, AI Quota Status
- **Finance**: Read-Only Prompt 05 Ledger Wallet Status (`PROMPT_05_LEDGER_CONNECTED`)

## Universal Activity Timeline
Aggregates real-time audit logs across Network, CRM, Billing, Automation, and Security with actor attribution and deep-link routing.
