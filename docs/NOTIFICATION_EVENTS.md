# Notification Application Events

- `NotificationDispatched`: Triggered when a message is queued for provider send.
- `NotificationDelivered`: Triggered when provider reports successful delivery.
- `NotificationFailed`: Triggered when provider reports delivery failure.
- `NotificationBounced`: Triggered when bounce notification is received.
- `NotificationSuppressed`: Triggered when recipient preferences or quiet hours suppress message.
- `CampaignStarted`: Triggered when mass outreach campaign begins.
- `CampaignCompleted`: Triggered when batch outreach completes.
